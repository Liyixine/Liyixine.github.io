发表于2025-11-30
记第一次全栈开发经历 一.知识预备我在之前了解到一位学长的创业产品Mentiforce，这是一个基于AI的学习系统。此次项目起源于在Mentiforce上的一项任务，即首先利用Mentiforce上快速学习了大量知识，如何与伙伴着手开发一个LLM的应用学习的知识主要为操作系统学习了进程模型、文件系统、环境变量以及网络端口等基础知识，让我能够从操作系统层面理解一条命令被执行时，进程是如何被创建、调度并参与网络通信的。Node.js 与 V8通过理解 V8 的 JavaScript 执行过程以及 Node.js 中事件循环和异步 IO 的机制，我明白了 Node 如何在单线程模型下高效处理大量 IO 请求，以及它在 CPU 密集型场景下的天然限制。浏览器与请求链路围绕一次完整的访问流程，我学习了 URL 解析、浏览器发起请求、跨域限制以及本地文件与开发服务器的区别，从而能解释浏览器与服务器之间是如何协作完成资源加载的。浏览器渲染与 React理解浏览器的 DOM 构建和渲染过程，并结合 React 的虚拟 DOM 和状态驱动渲染机制，我了解了页面是如何在状态变化后完成更新的。工程化与...
